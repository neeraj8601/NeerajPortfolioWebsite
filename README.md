# Neeraj Kumar — Portfolio Website

A responsive developer portfolio inspired by the supplied screenshots.

## Stack
- HTML5
- Custom CSS
- JavaScript
- Tailwind CSS CDN
- Bootstrap 5 CDN
- Bootstrap Icons CDN
- Google Fonts CDN

## Files
- `index.html` — all portfolio sections
- `style.css` — custom design and responsive styling
- `script.js` — navigation, theme switcher, scroll effects and form validation

## Run
1. Open `index.html` directly in a browser, or use VS Code + Live Server.
2. Internet access is needed for Tailwind, Bootstrap, Bootstrap Icons and Google Fonts CDNs.

## Before publishing
Search in `index.html` for:
- `your-email@example.com`
- `+91 XXXXX XXXXX`
- `href="#"`

Replace them with your real contact/social links.

The contact form is frontend-only. Connect it to Formspree, EmailJS, or your own backend when you want real message delivery.
